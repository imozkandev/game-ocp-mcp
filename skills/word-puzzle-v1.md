# Word Puzzle Level Generator — v1

Create a fun mobile word-puzzle level for the requested theme and difficulty.

Return a grid and a list of words that the player should find. Make the puzzle feel appropriate for the difficulty, keep the words relevant to the theme, and include a short hint when useful.

Try to avoid repeating words and make sure the level is playable.

## Request

Use the level request supplied by the caller to decide the theme, grid size, and number of words.

## Notes

- Prefer simple, familiar words for easy levels.
- Make hard levels more challenging.
- You may add fields that help describe the level.
