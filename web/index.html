TOOL 01

Level balance linter

Prevent bad progression tuning from reaching players. It flags balance anomalies while preserving valid level data.

HOW IT WORKS

  1. 01Reads a level JSON file.
  2. 02Validates levelId, score, moves, and rewards.
  3. 03Flags zero rewards, invalid moves, and sudden move spikes.

Accepts a top-level array or { "levels": [...] }.

TOOL 02

Localization audit

Keep every language complete and safe for runtime string interpolation before a release.

HOW IT WORKS

  1. 01Loads a base locale, usually en.json.
  2. 02Compares every target key against that reference.
  3. 03Reports missing keys and mismatched {param} values.

The sample tr.json intentionally has one missing key and one broken {playerName} variable.

TOOL 03

Agent eval runner

Score generated content with deterministic assertions instead of trusting a model’s own assessment.

HOW IT WORKS

  1. 01Parses generated content with a strict schema.
  2. 02Runs task-specific assertions.
  3. 03Returns pass/fail scenarios and a 0–100 score.

TOOL 04

Unity Guard

Catch performance and Inspector API regressions in Unity C# before they reach a commit.

WHAT IT CHECKS

  1. 01Scans Update, LateUpdate, and FixedUpdate.
  2. 02Flags allocations, LINQ, component lookups, and scene searches.
  3. 03Suggests [SerializeField] private for public Inspector fields.

The bad sample reports frame-loop violations. The clean sample caches references and passes the scan.

TOOL 05

Agent Monitor

See the Claude, Cursor, Codex, MCP, and Python processes running on this machine before they become invisible background work.

WHAT YOU SEE

  1. 01Discovers local agent processes by command.
  2. 02Collects PID, CPU, memory, and uptime.
  3. 03Audits logs for rate-limit and connection failures.

Live refresh runs only while this tab is open. Process and log data stay on this machine.

TOOL 06

Skill Eval CI

Prove that a prompt improvement is actually better before it lands in a pull request.

HOW IT WORKS

  1. 01Uses the weak v1 output as a committed baseline.
  2. 02Runs the v2 fixture through JSON and content assertions.
  3. 03Calculates the delta and formats a PR-ready Markdown comment.
